PRH Company Finder

Complete Finnish company data from PRH APIs

⚠️ GitHub Pages Static Version - Limited by CORS policies. For full functionality, use the Flask application.

Data to Return

ℹ️ What can be fetched?

Available Data from APIs:

  • YTJ (Business Information System): Business ID, official name, company form, registration date, addresses, website URL
  • Registered Notices: Registration dates, entry codes, descriptions, decision makers (parsed from entries when available)
  • XBRL Financial Data: List of financial periods with dates, specific financial statement XML for any period

Note: Decision makers are parsed from registered notices. If parsing fails, raw registered entries are shown as fallback.

CORS Limitation: Some PRH APIs may block direct browser requests due to CORS policies. In such cases, mock data is displayed for demonstration purposes. For full functionality, please use the Flask application.
