Haettavat tiedot

ℹ️ Mitä tietoja voidaan hakea?

Saatavilla olevat tiedot rajapinnoista:

  • YTJ (Yritys- ja yhteisötietojärjestelmä): Y-tunnus, virallinen nimi, yhtiömuoto, rekisteröintipäivä, osoitteet, kotisivun URL
  • Rekisterimerkinnät: Rekisteröintipäivät, merkintäkoodit, kuvaukset, päättäjät (jäsennetty merkinnöistä kun saatavilla)
  • XBRL-tilinpäätöstiedot: Lista tilikausista päivämäärineen, yksittäiset tilinpäätökset XML-muodossa

Huomio: Päättäjät jäsennetään rekisterimerkinnöistä. Jos jäsennys epäonnistuu, näytetään raakatiedot varasuunnitelmana.

CORS-rajoitus: Jotkin PRH:n API:t saattavat estää suorat selainpyynnöt CORS-politiikoiden vuoksi. Tällöin näytetään esittelytarkoitukseen kokonaisdataa. Täydellisen toiminnallisuuden saat käyttämällä Flask-sovellusta.
